Database Backup & Restore

पूरे portal का backup JSON file में डाउनलोड करें। Restore करने पर मौजूदा Users, Cities और Results backup वाले data से replace होंगे।

सुरक्षा: Backup file में user password hashes शामिल हैं। इसे किसी के साथ साझा न करें। Restore से पहले वर्तमान data का backup डाउनलोड कर लें।
