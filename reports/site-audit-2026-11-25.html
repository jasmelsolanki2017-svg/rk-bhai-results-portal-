अच्छी सुरक्षा व्यवस्थाएँ जो मिलीं

  • Admin HTML routes static serving से पहले session check करते हैं।
  • Passwords bcrypt से hash किए जाते हैं।
  • Session cookies HttpOnly और SameSite=Strict हैं; production में Secure flag भी है।
  • Helmet security headers enabled हैं (CSP को छोड़कर)।
  • Admin login पर basic in-memory throttle है।
  • CSV export spreadsheet formula-leading characters को neutralize करता है।
  • Public results API published और non-deleted records को filter करती है।
  • GitHub Pages workflow public-facing files बनाता है; Admin Panel files deploy bundle में शामिल नहीं करता।
